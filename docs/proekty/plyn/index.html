Сайт, после которого хочется прийти на первое занятие

Йогу выбирают по ощущению: спокойно ли здесь, понятно ли новичку, сколько стоит начать. Поэтому сайт говорит тихо — светлые карточки, много воздуха, живые фото — и сразу отвечает на главные вопросы: какие есть направления, сколько стоит первое занятие и как записаться.

( задача )

Придумать студии название и логотип и собрать сайт, который ведёт от первого впечатления к записи на пробное занятие: направления, цены, аренда залов и сертификаты — без звонков и поиска по разделам.

( стек работ )

    ( 05 )

    Отдельная страница стоимости: вкладки для новичков, абонементов, персональных занятий и аштанги, цены крупно, рядом — что входит в абонемент.

    Подарочный сертификат оформляется в три шага, два зала для аренды показаны с фото и заявкой прямо в карточке.
