# Сайт студии clue

## Структура

```
src/        здесь работаем
  pages/      index.html — главная; kontakty.html и другие — содержимое обычных страниц
  data/       uslugi/*.json — услуги, proekty/*.json — кейсы
  assets/     стили, скрипты, шрифты, картинки
tools/      генераторы; build.py собирает весь сайт
docs/       готовый сайт (его публикует GitHub Pages), руками не править
```

Собрать сайт: `python tools/build.py` — пересоздаёт папку docs целиком.

Новая услуга — файл в `src/data/uslugi/`, новый кейс — в `src/data/proekty/`,
новая страница — `src/pages/<адрес>.html` (вверху строки title, description, nav).
Адрес страницы = имя файла: `kontakty.html` → `/kontakty/`.

GitHub Pages: Settings → Pages → Deploy from a branch → папка `/docs`.

# clue — главная (код)

Готовая вёрстка всей главной в стиле «белые карточки на сером». Без библиотек: HTML + CSS + JS.

## Структура
- `index.html` — разметка: шапка, мобильное меню, первый экран, полоса «проекты», «Начните с задачи» (4 задачи), «Первый шаг», «Концепты», «Услуги и стоимость» + «От чего зависит сумма», «Как работаем», «Вопросы», «Заявка», футер.
- `assets/css/style.css` — все стили и токены (`:root`), адаптив: 1180 / 960 / 640 px.
- `assets/js/main.js` — шапка (прячется при прокрутке вниз), мобильное меню (Esc, фокус, aria), появление блоков при прокрутке, плавное раскрытие вопросов, проверка и отправка формы.
- `assets/fonts/` — Inter Display 400 и 500 (лицензия SIL OFL, можно размещать на сайте).
- `assets/img/logo/` — логотип clue, белый логотип, favicon.
- `assets/img/concepts/` — экраны концептов VECTOR, NORTH, INDEX, FORMA.

## Просмотр локально
Шрифты не грузятся при открытии файла двойным кликом. Запусти сервер в папке: `npx serve .` или `python3 -m http.server`.

## Перенос в Eleventy
1. Папку `assets` скопируй в `src/assets` и добавь `eleventyConfig.addPassthroughCopy("src/assets")`.
2. Шапку и мобильное меню вынеси в `_includes/header.njk`, каждый блок главной — в отдельный include.
3. Ссылки сделай от корня (`/uslugi/`, `/assets/...`). Если сайт на GitHub Pages в подпапке репозитория — через фильтр `| url` и `pathPrefix`.
4. Список услуг и цены вынеси в `_data/services.json` и выводи циклом (одни данные для главной, страницы «Услуги» и меню).
5. Ничего не упрощай: размеры, отступы, скругления и анимации — как в `style.css`.

## Что заполнить
- Страницы, на которые ведут ссылки (`proekty/`, `uslugi/...`, `o-studii/`, `kontakty/`), пока не существуют.
- `og:image` — добавить, когда будет картинка для соцсетей.
- Ссылки Telegram и Email: впиши их один раз в `assets/js/main.js`, в объект `CONTACTS` в начале файла. Они подставятся во все кнопки сайта, включая большой синий круг «написать в Telegram».
- Отправка формы: на GitHub Pages нет сервера. Подключи сервис форм (например, Formspree) и впиши его адрес в `data-endpoint` у `<form>`. Пока адреса нет, форма проверяет поля и показывает «Форма пока не подключена».

## Логотипы Notion и Figma
В блоке «Вы видите проект на каждом этапе» ждут официальные значки:
- `assets/img/brands/Notion.webp` (имя с большой буквы — на GitHub Pages регистр важен)
- `assets/img/brands/figma.svg`

Скачай их с официальных страниц бренда (Notion — notion.com/brand, Figma — figma.com/using-the-figma-brand) и положи по этим путям. Пока файлов нет, вместо них показываются простые значки студии.

## Проверка
- 1440, 900 и 390 px: нет горизонтального скролла.
- Меню на мобильном открывается и закрывается по кнопке, Esc и тапу по ссылке.
- Вопросы раскрываются и закрываются плавно.
- Форма: пустой контакт и снятая галочка подсвечиваются ошибкой, фокус переходит на поле.
- В DevTools включи «prefers-reduced-motion: reduce» — анимаций нет, всё видно сразу.

## Устройства (макеты)

Все устройства собираются кодом в `tools/devices.py`: iPhone, iPad, MacBook, окно браузера,
объёмный телефон и подиум. Экраны — обычные картинки, их можно заменить на свои:

- телефон — 780×1688 (экран 390×844 @2x), без рамки: рамку, Dynamic Island и тень рисует сайт;
- планшет — ~1770×1230 (горизонтально), ноутбук и браузер — 16:10 (2160×1350).

Строка состояния 9:41 рисуется поверх экрана телефона. В `phone(..., sb=...)`:
`'light'` — белая (тёмный экран), `'dark'` — чёрная (светлый экран), `'none'` — убрать
(если на скриншоте из Figma она уже есть). Цвет рамки телефона: класс `dv-ph--silver` — серебристый.


## Форма заявки

`backend/form-handler/` — обработчик формы для Yandex Cloud Functions (антиспам, хранение копий, отправка на почту и в Telegram).
Пошаговая настройка — `backend/form-handler/nastroika.md`. Готовый архив для загрузки — `backend/form-handler.zip`.
Адрес функции и ключ капчи вписываются в `src/assets/js/main.js` → `const FORM`.
