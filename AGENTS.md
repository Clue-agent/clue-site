# AGENTS.md — памятка для ИИ-ассистентов и разработчиков

Прочитай этот файл целиком, прежде чем что-то менять. Здесь описано, что это за проект,
как он устроен, как собрать и опубликовать сайт и какие правила принял владелец.
Если что-то в проекте поменялось — обнови этот файл в том же коммите.
В Claude Code сверить файл с проектом и обновить его можно командой `/update-agents`
(скилл в `.claude/skills/update-agents/`).

## Что это

Сайт веб-студии **clue** (Могилёв, Беларусь): разработка сайтов, дизайн, SEO.
Статический сайт без фреймворков: HTML + CSS + JS, страницы собираются Python-скриптами.

- Сайт: https://clue.by (HTTPS, сертификат Let's Encrypt выпускает и продлевает GitHub)
- Репозиторий: https://github.com/Clue-agent/clue-site (публичный, ветка `main`)
- Хостинг: GitHub Pages, ветка `main`, папка `/docs`
- Домен и DNS: регистратор hoster.by, DNS-серверы `u1.hoster.by` / `u2.hoster.by`,
  записи: 4 × A `clue.by` → `185.199.108–111.153`, CNAME `www` → `clue-agent.github.io.`
- Язык сайта и общения с владельцем — русский.

## Структура

```
src/                  исходники — работаем только здесь
  pages/              страницы: index.html — главная целиком; остальные — только содержимое
                      имя файла = адрес: kontakty.html → /kontakty/, uslugi--lending.html → /uslugi/lending/
  data/uslugi/*.json  страницы услуг → /uslugi/<slug>/      (генератор tools/gen_service.py)
  data/proekty/*.json кейсы → /proekty/<slug>/              (генератор tools/gen_case.py)
  assets/             css/style.css (все стили), js/main.js (весь JS), шрифты, картинки
  root/               файлы, которые кладутся в корень сайта как есть (подтверждение Яндекс.Вебмастера)
tools/
  build.py            сборка всего сайта src/ → docs/
  gen_service.py      шаблон услуг; отсюда же HEADER/MNAV/FOOTER/MODAL, вырезанные из index.html
  gen_case.py         шаблон кейса; список OTHERS — карточки «Другие проекты»
  gen_page.py         обычные страницы из src/pages/
  seo.py              домен, canonical, OG, JSON-LD, sitemap.xml, robots.txt, CNAME; цены услуг для разметки
  devices.py          макеты устройств (телефон, планшет, ноутбук) для кейсов
docs/                 готовый сайт. Руками НЕ править: build.py удаляет и пересоздаёт папку целиком
backend/form-handler/ функция Yandex Cloud для формы заявки (сейчас не развёрнута, см. «Форма»)
brand/                логотипы, фавиконки, аватары для соцсетей (исходники, на сайт не идут)
_cases/  _versions/  tmp/   рабочие материалы, в .gitignore, в репозиторий не попадают
```

`README.md` частично устарел (например, про Formspree и «страницы пока не существуют») —
верь этому файлу и коду.

## Сборка и просмотр

```
py tools/build.py
```

Пиши именно `py`: команда `python` на этом компьютере открывает заглушку Microsoft Store.
Успешная сборка печатает `готово: N страниц …`. Если N неожиданно изменилось — разберись, почему.

Локальный просмотр: `py -m http.server 8080 --directory docs` (настроено в `.claude/launch.json`
как сервер `site`), затем http://localhost:8080. Шрифты не грузятся при открытии файла двойным кликом.

Перед публикацией проверь: ширины 375 / 768 / 1440 px без горизонтальной прокрутки,
нет ошибок в консоли, ссылки и картинки открываются.

## Публикация

```
py tools/build.py
git add <нужные файлы> docs
git commit -m "…"
git push
```

Через 1–2 минуты GitHub Pages выкладывает новую версию.

Особенности этого компьютера:
- Пуш идёт по HTTPS от аккаунта GitHub **Clue-agent** (gh CLI авторизован под ним).
  SSH-ключ на компьютере принадлежит другому аккаунту (Test-mercenary), поэтому `origin` — HTTPS.
  Если обычный `git push` просит пароль или получает отказ, используй токен gh:
  `git -c credential.helper= -c "credential.helper=!gh auth git-credential" push origin main`
  (или один раз `gh auth setup-git`).
- `docs/CNAME` (= `clue.by`) создаёт seo.py. Не удаляй его и не меняй домен в настройках Pages:
  GitHub сам делает коммиты в `docs/CNAME`, после этого нужен `git pull`.

## Как устроены страницы

- **Шапка, меню, мобильное меню, футер и окно заявки** у всех страниц берутся из `src/pages/index.html`
  (gen_service.py вырезает их по комментариям `<!-- ШАПКА -->` и т. д.). Правишь меню или футер —
  правь `index.html`, остальные страницы обновятся при сборке.
- В `src/` все ссылки пишутся от корня сайта без `/` в начале (`uslugi/lending/`, `assets/...`);
  генераторы сами переписывают их в относительные (`../../uslugi/lending/`).
- Обычная страница начинается со служебных строк:
  `<!--title: …-->`, `<!--description: …-->`, `<!--nav: uslugi-->` (какой пункт меню подсветить).
- build.py: ссылки на услуги без своей страницы ведут к строке на `/uslugi/`; карточки кейсов без страницы
  показываются без ссылки.

### Новый кейс
1. Скриншоты клиента владелец кладёт в `_cases/<имя>/`.
2. Картинки → `src/assets/img/cases/<slug>/` (те же имена, что у других кейсов: d-hero, m-hero, p-home …),
   обложка 1200×760 → `src/assets/img/concepts/<slug>.webp`.
3. Данные → `src/data/proekty/<slug>.json` (скопируй структуру существующего, например `mira.json`).
4. Карточка на `src/pages/proekty.html`; запись в `OTHERS` в `tools/gen_case.py`;
   на главную (`index.html`) — только если владелец попросит.
5. Сборка, проверка, что в тексте не осталось кусков чужого кейса, коммит, пуш.

Для редизайна сайта клиента в концепт-кейс есть скилл Claude Code `redesign-to-portfolio-case`.

### Отраслевая страница (`/otrasli/<slug>/`)
Файл `src/pages/otrasli--<slug>.html`. Отраслевые страницы — это не услуги:
- в выпадающее и мобильное меню «Услуги» их **не добавлять** (решение владельца);
- ссылка — в колонке футера «отрасли» в `index.html`;
- блок со ссылкой из подходящего кейса — поле `"industry"` в json кейса;
- вопрос «Делаете сайты под отрасль?» на `src/pages/uslugi--sait-kompanii.html` — дописать новую отрасль;
- цена и приоритет — в `SERVICE_PRICE` и `PRIORITY` в `tools/seo.py`.

### Цены
Цена одной услуги записана в нескольких местах — меняй во всех:
title/description и тексты страницы, меню в `index.html`, `src/pages/uslugi.html`, json кейсов (`industry`),
`SERVICE_PRICE` в `tools/seo.py`, подсказка в `src/assets/js/main.js`.
Текущие: визитка от 1 500, лендинг от 1 200, сайт компании от 2 500, редизайн от 1 500,
сайт для автосалона от 1 700, сайт для студии от 1 500 BYN.

## Форма заявки

Сейчас работает через **Web3Forms** с hCaptcha: заявки приходят на почту аккаунта Web3Forms.
Настройки — объект `FORM` в `src/assets/js/main.js`. `web3formsKey` — публичный ключ формы,
он и должен лежать в коде.

`backend/form-handler/` — запасной вариант: своя функция в Yandex Cloud (антиспам, копия в хранилище,
почта + Telegram, Yandex SmartCaptcha). Не развёрнута. Инструкция — `backend/form-handler/nastroika.md`;
после развёртывания вписать `FORM.endpoint` и `FORM.captchaKey`.

## Правила владельца

- Делай только то, о чём просили. Нашёл чужие незакоммиченные правки — не публикуй их молча,
  спроси. Публикуй только проверенное.
- Временные файлы и черновики — в `D:\myprogekt\tmp`, не на диске C:.
- Секреты (токены, пароли, серверные ключи) не хранить в репозитории и не просить их в переписке.
  Репозиторий публичный.
- Картинки-генераторы (Gemini) не используются; иллюстрации и значки — SVG вручную.
- Правила работы с кодом — в `CLAUDE.md`: минимальные точечные изменения, без лишних абстракций,
  проверка результата перед тем, как сказать «готово».
